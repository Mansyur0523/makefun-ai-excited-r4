# Koi Through the Moon

A giant koi leaps through the full moon — its splashing water turning into golden stars — while a tiny lantern boat drifts far below. One focus, one strong diagonal, one thrilling moment.

Built for [ai-excited-01](https://make.fun/bounty/ai-excited-01) on make.fun. `main.py` (pure Python standard library, no dependencies) draws the image deterministically and writes `entry.png` (1024×1024).
